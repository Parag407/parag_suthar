## ✅ How to Add Your Images

1. **Gallery photos** → Drop any `.jpg`/`.png` file into `public/assets/gallery/`  
   Name them exactly as listed above so they auto-load in the Gallery page.

2. **Project screenshots** → Drop into `public/assets/projects/`  
   Any image shows immediately as the project card thumbnail.

3. **Profile photo** → Replace `public/assets/profile/parag_profile_pic.jpeg`  
   Keep the same filename, or update `HeroSection.jsx` with the new name.

> **No build step needed** — just drop the file and refresh the browser.
